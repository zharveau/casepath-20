# CasePath — Tort Law Prototype

Open `index.html` in a modern browser.

This version is scoped exclusively to tort law, with intake categories such as negligence, occupiers' liability, motor vehicle accidents, defamation, nuisance, trespass, and product liability.

The form, step navigation, illustrative cost calculator, results overview, and print view work in-browser. This is a front-end demo only: it does not use an AI model, analyze uploaded files, store information, determine tort liability, calculate damages, or connect users with lawyers.

For production, add secure backend infrastructure, privacy and consent controls, a real AI service with human-reviewed safeguards, jurisdiction-specific tort-law logic, validated damages methodology, and qualified lawyer oversight.
